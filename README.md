# 📊 Análise de Audiência

Este projeto utiliza **Python**, **Pandas** e **Matplotlib** para analisar e visualizar dados de visitas ao longo de quatro semanas. Foram calculadas estatísticas como **média, mediana e desvio padrão**, além da geração de diferentes tipos de gráficos para interpretação dos dados.

## 🛠️ Tecnologias Utilizadas
- Python 3
- Pandas
- NumPy
- Matplotlib

## 📂 Estrutura do Projeto
```
/
├── script.py  # Código principal
├── README.md  # Documentação do projeto
└── requisitos.txt  # Bibliotecas necessárias
```

## 📈 Funcionalidades
- Cálculo de estatísticas descritivas:
  - **Média** das visitas por semana
  - **Mediana** das visitas por semana
  - **Desvio padrão** das visitas por semana
- Visualização de dados:
  - Gráfico de **barras** para comparar a média semanal
  - Gráfico de **linhas** para ver a variação ao longo dos dias
  - Gráfico **boxplot** para analisar a distribuição dos dados

## 🚀 Como Executar o Projeto
1. **Clone o repositório**:
   ```bash
   git clone https://github.com/AlexsandraMCamposo/audiencia.git
   cd audiencia
   ```

2. **Crie um ambiente virtual e instale as dependências**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\Scripts\activate  # Windows
   pip install -r requisitos.txt
   ```

3. **Execute o script**:
   ```bash
   python script.py
   ```
